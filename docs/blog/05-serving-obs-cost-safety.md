# 05 · 服务、观测、成本与安全：闭源/开源、评测、路由与 Guardrail

## 当时业务痛点

演示很惊艳，一进生产就三连崩：

1. **延迟**：首 token 慢，用户以为卡死；全量 JSON 又等太久。
2. **账单**：周末一次 Agent 死循环，工具日志刷爆，早会财务报表先到。
3. **事故**：模型把工单里的手机号原样回给无关坐席；或一本正经幻觉政策。
4. **不会改**：没有 trace，不知道坏在检索、工具还是提示词；没有黄金集，改 prompt 只能靠感觉。

这是同一类问题：**把模型当系统，却没按系统去服务、观测、计费和设防。**

## 当时怎么看这个问题

服务层要回答：模型从哪来、流式怎么切、结构化怎么约束。观测层要回答：一次请求的因果链。评估层要回答：改动是变好还是变差。成本与安全是横切——路由、缓存、护栏、PII——它们不是上线前的检查表，而是**运行时架构**。

## 试过什么

### 模型服务

1. **只接一家闭源 API**：质量稳、功能全；出境、单价、限流、停服风险要预案。
2. **自宿开源权重**：数据可控、可微调；要吃 GPU、工程与安全补丁。
3. **结构化输出**：JSON mode / schema；仍要服务端校验，不信模型一次成型。
4. **流式 SSE 到前端**：体验好；取消、半截工具调用、网关缓冲要设计。

### 观测与评估

1. **只打应用日志**：缺 span 关联，Agent 多步对不上。
2. **全量人工看答案**：不可扩展。
3. **上线后才评**：回归靠用户投诉。
4. **离线黄金集 + 在线抽样 + trace**：可管，但要维护成本。

### 成本 / 延迟 / 安全

1. **一律最强模型**：贵且慢。
2. **无缓存重复检索/重复系统提示**：浪费。
3. **靠 prompt 防泄露**：不够。
4. **出口正则脱敏 + 工具 ACL + 路由小模型**：有效，需持续调。

## 为什么否决

| 选项 | 原因 |
|------|------|
| **无双供的单一闭源依赖** | 否决作为唯一生产通路（至少要有降级或只读缓存预案）。 |
| **无 schema 校验的「模型保证 JSON」** | 否决。 |
| **无 trace 的多步 Agent 上生产** | 否决。 |
| **只靠在线用户反馈当评测** | 否决作为唯一质量信号。 |
| **最大模型打天下** | 否决默认路由。 |
| **Prompt-only 安全** | 否决。要网关 ACL、PII 过滤、输出检查。 |

## 最终怎么解

### 1) Serving & models

| 选项 | 优点 | 缺点 | 场景 |
|------|------|------|------|
| 闭源 API | 质量/功能/运维省 | 数据出境与议价、限流 | 默认智能、工具调用密集 |
| 开源自宿 | 可控、可私有化 | GPU 与工程成本 | 敏感数据、稳定高 QPS 模板任务 |
| 混合路由 | 成本与质量平衡 | 路由策略要评测 | **推荐默认**：简单→小/本地，难→大 |

流式：UI 走 token 流；工具调用边界要「缓冲到合法帧」再执行。结构化：schema 生成 + 服务端校验 + 失败重试一次严格模式。

### 2) Observability & eval

| 手段 | 用途 |
|------|------|
| **Trace / Span**（请求→检索→工具→模型） | 排障、归因、费用归集 |
| **黄金集离线评** | 改 prompt/检索不盲飞 |
| **在线抽样 + 用户信号** | 分布漂移 |
| **回归门禁** | CI 里跑关键集，坏了不发版 |

姊妹仓：[agent-observability](https://github.com/jianwen049-hub/agent-observability) · [ai-eval-lab](https://github.com/jianwen049-hub/ai-eval-lab)

### 3) Cost / latency / safety

| 杠杆 | 做法 |
|------|------|
| **路由** | 分类器/规则：FAQ 走小模型或缓存；复杂推理走大模型 |
| **缓存** | 语义缓存要慎（错误会固化）；精确缓存系统提示/检索热键更稳 |
| **预算** | 每请求 token / 费用硬顶，Agent 步数硬顶 |
| **Guardrail** | 输入注入检测、输出政策、工具 ACL |
| **PII** | 入模前脱敏、出模后扫描、日志落盘分级 |

姊妹仓：[llm-cost-latency](https://github.com/jianwen049-hub/llm-cost-latency)

## 用到的具体 skill / 技巧清单

| Skill | 用法 |
|-------|------|
| **双供与降级** | 主模型挂了只读缓存或小模型致歉 |
| **流式与工具分相** | 展示可流，执行要完整帧 |
| **Schema + 校验** | 结构化输出两道闸 |
| **Trace 必打费用** | 成本和质量同一条因果链 |
| **离线门禁** | 黄金集不过不发版 |
| **路由省钱** | 不是损质量，是把简单题分流 |
| **PII 分层** | 训练/日志/回答/工具参数各有策略 |
